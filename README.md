# 📝 Android Kotlin Notes

Приложение для заметок на Android, написанное на Kotlin с использованием Jetpack Compose

Второй pet-проект в разработке под Android, в котором я углубился в Clean 
Architecture, реактивные потоки данных и навигацию между экранами

## 📱 Возможности

- Просмотр списка заметок с разделением на закреплённые и остальные 
- Поиск заметок по заголовку и содержимому
- Закрепление / открепление заметки (долгое нажатие на заметку)
- Удаление заметки 
- Создание новой заметки (отдельный экран)
- Редактирование существующей заметки (отдельный экран)
- Навигация между экранами: список всех заметок → создание заметки → редактирование заметки
- Постоянное хранение данных в локальной базе данных (Room)

## 🚧 В планах

- Добавление изображений к заметкам
- Финальная доработка и тестирование перехода на Room

## 🛠 Стек технологий

- Kotlin
- Jetpack Compose
- Navigation Compose
- Clean Architecture (data / domain / presentation)
- MVVM (ViewModel + StateFlow)
- Use Case паттерн (отдельный класс на каждое действие: добавление, 
  удаление, редактирование, поиск и т.д.)
- Kotlin Coroutines & Flow
- Room (локальная база данных)

## 🚀 Запуск проекта

1. Склонируйте репозиторий:
```bash
   git clone https://github.com/arigfk/android_kotlin_notes.git
```
2. Откройте проект в Android Studio
3. Дождитесь синхронизации Gradle
4. Запустите на эмуляторе или устройстве
