# 📝 Android Kotlin Notes

Приложение для заметок на Android, написанное на Kotlin с использованием Jetpack Compose.

Второй pet-проект в разработке под Android, в котором я углубился в Clean 
Architecture и работу с реактивными потоками данных.

⚠️ **Проект находится в разработке** — базовый функционал работает, но часть 
экранов и хранение данных ещё предстоит реализовать (подробнее в разделе "В планах").

## 📱 Возможности (реализовано)

- Просмотр списка заметок с разделением на закреплённые и остальные
- Поиск заметок по заголовку и содержимому
- Закрепление / открепление заметки (долгое нажатие на карточку)
- Удаление заметки (временно — двойной клик по карточке)
- Редактирование заметки (временная реализация — полноценный экран редактирования в разработке)

## 🚧 В планах

- Полноценный экран создания и редактирования заметки
- Постоянное хранение данных (сейчас используется репозиторий в памяти, 
  данные не сохраняются между запусками — планируется переход на Room)
- Нормальный UX для удаления (свайп или кнопка вместо двойного клика)
- Уборка тестовых данных и отладочного кода

## 🛠 Стек технологий

- Kotlin
- Jetpack Compose
- Clean Architecture (data / domain / presentation слои)
- MVVM (ViewModel + StateFlow)
- Use Case паттерн (отдельный класс на каждое действие: добавление, 
  удаление, редактирование, поиск и т.д.)
- Kotlin Coroutines & Flow
- Figma

## 🚀 Запуск проекта

1. Склонируйте репозиторий:
```bash
   git clone https://github.com/arigfk/android_kotlin_notes.git
```
2. Откройте проект в Android Studio
3. Дождитесь синхронизации Gradle
4. Запустите на эмуляторе или устройстве
